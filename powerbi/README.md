# Power BI Assets

Apply `Online_Retail_Midnight_Navy.json` via View → Themes → Browse for themes in Power BI Desktop.

Use `Measures.dax` as a reference: create each measure separately through Modeling → New measure. Calculated columns (YearMonth and YearMonthSort) should be created using Modeling → New column. If the source boolean field differs in type/name, adapt the formula.

The theme/reference pack is not itself a binary PBIX. Save the final report from Power BI Desktop after confirming source paths and visual rendering.
